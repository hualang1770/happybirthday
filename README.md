# 生日网页上传包

这个文件夹里的内容就是可发布的静态网站，不需要安装依赖或构建。

将**文件夹内的全部内容**上传到 GitHub 仓库根目录，确保 `index.html` 位于仓库根目录。然后在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`。

上传包只含网页、图片和音乐，没有聊天导出或本地祝福草稿。发布后，拿到链接的人可以看到页面上的姓名、头像和信件。

Chrome 通常会阻止首次打开时直接播放有声音乐。页面会先尝试自动播放；若被拦截，点击开场按钮后以 50% 音量播放。
